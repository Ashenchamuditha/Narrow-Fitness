## Projects

### Narrow Fitness – Comprehensive Gym Management Platform
**Full-Stack Web Application | Individual Final Year Project**

Engineered a complete gym management system with AI-powered fitness assistance, enabling seamless member enrollment, class scheduling, automated payment processing with SMS/Email notifications, and personalized workout guidance. Implemented role-based access control for Members, Trainers, and Admins with secure JWT authentication.

**Key Achievements:**
- Integrated **Groq Llama 3.3 AI** for real-time personalized workout & nutrition recommendations with persistent chat history
- Built **three-tier RBAC system** with JWT-based authentication and bcryptjs password hashing
- Designed **smart payment blocking system** that automatically restricts feature access for unpaid members with automated renewal date tracking and grace period configuration
- Implemented **multi-channel notification system** using Nodemailer (Email) and SMS Gateway for payment reminders, confirmations, and class updates
- Created **WebSocket real-time communication** via Socket.io for live class notifications, AI chat synchronization, and payment status updates
- Built **subscription management** with package tiers (Basic/Pro/Premium), pro-rata adjustments, and payment history tracking
- Designed **PostgreSQL schema** with 12+ tables deployed on Neon Cloud with dual-mode local/production configuration
- Implemented **comprehensive payment retry mechanism** with failure handling and 7-day pre-expiration notifications

**Tech Stack:** TypeScript | React 19 | Express.js | PostgreSQL | Groq AI (Llama 3.3) | Socket.io | JWT | Nodemailer | SMS Integration | Tailwind CSS

**Repository:** [GitHub Link](https://github.com/Ashenchamuditha/Narrow-Fitness)
